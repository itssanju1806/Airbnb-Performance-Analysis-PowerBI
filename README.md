## 📌 Project Overview

This project presents an end-to-end **Airbnb Performance Analysis using Microsoft Power BI**, developed to demonstrate how data analytics, visualization, and DAX can be used to solve real-world business problems and generate actionable insights from Airbnb listing and review data.

The analysis focuses on **listing distribution, market concentration, pricing, accommodation types, guest ratings, reviewer behavior, host verification, profile-picture adoption, and seasonal review activity** across major Airbnb markets.

The project transforms raw listing and review data into an interactive Power BI dashboard containing three analytical perspectives:

- **Overview**
- **Ratings**
- **Reviews**

The dashboard combines KPI reporting, comparative analysis, cumulative/Pareto analysis, rating heatmaps, review-frequency analysis, host trust segmentation, and seasonal trend analysis to provide a comprehensive view of Airbnb marketplace performance.

# 📊 Dashboard Overview

The Power BI dashboard is organized into three major analytical sections.

---

## 🏠 1. Overview Dashboard

The Overview page provides a high-level snapshot of Airbnb marketplace performance.

### Key Analysis Areas

- Total Listings
- Total Reviews
- Total Reviewers
- Average Price
- Listing distribution by city
- Listing concentration
- Average price by accommodation type
- Major market comparison

### Key Insight

The top 5 cities—**Paris, New York, Sydney, Rome, and Rio de Janeiro**—account for approximately **68% of total listings**, while the top 7 cities contribute around **84%**, demonstrating a highly concentrated marketplace.

### Pricing Insight

**Hotel rooms have the highest average price at approximately $800**, followed by:

- Entire Places — $673
- Shared Rooms — $580
- Private Rooms — $462

This highlights a clear pricing premium associated with hotel-style accommodation.

---

# ⭐ 2. Ratings Dashboard

### Rating Dimensions Analyzed

- Check-in
- Cleanliness
- Communication

### Key Analysis Areas

- City-level rating comparison
- Rating dimension comparison
- Heatmap-based performance analysis

This indicates generally strong guest satisfaction while highlighting opportunities to identify specific dimensions requiring improvement.

## 📈 Review Frequency Analysis

The review-frequency analysis evaluates how many reviews individual reviewers have submitted.

### Key Insight

**86.5% of reviewers have posted only one review**, while **96.6% have posted two or fewer reviews**.

The cumulative share reaches approximately **99.9% by five reviews**, highlighting the dominance of one-time and low-frequency reviewers.

### Business Value

This analysis helps understand reviewer engagement and indicates that highly active repeat reviewers represent only a small portion of the overall reviewer population.

---

## 🛡️ Host Trust Analysis

The host trust analysis evaluates identity verification and profile-picture availability.

### Trust Segments

- Verified + Profile Picture
- Verified + No Profile Picture
- Not Verified + Profile Picture
- Not Verified + No Profile Picture

### Key Insight

**66.9% of hosts are both identity-verified and have a profile picture**, making this the dominant host-trust segment.

### Business Value

This provides insight into host credibility and the extent to which hosts establish visible and verified identities on the platform.

---

## 📅 Seasonal Activity Analysis

The dashboard evaluates monthly review activity across major Airbnb markets.

### Key Insight

Clear seasonal variations can be observed across cities:

- **Paris and Rome** show stronger representation around **June–August**.
- **New York** gains prominence during **October–November**.
- **Sydney** shows stronger activity toward **November–December**.

These patterns indicate that marketplace activity varies by destination and season rather than remaining constant throughout the year.

### Business Value

Understanding seasonal market behavior can support:

- Seasonal planning
- Market-specific campaigns
- Host preparation
- Operational planning
- Demand-focused strategies

Review activity varies by market and month, with different cities showing stronger representation during different periods of the year.
